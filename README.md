# CompStock — учебный разбор

Откройте index.html в полноценном браузере. Интернет, сервер, MySQL и установка пакетов для чтения не нужны. Весь текст и код интерактивной версии уже встроен в index.html; внешних шрифтов и библиотек нет.

На телефоне просмотрщик вложений может не исполнять JavaScript. Откройте файл именно в браузере или используйте reading/index.html: это версия без JavaScript. Для неё извлеките архив целиком, сохранив папку reading.

## GitHub Pages

1. Создайте репозиторий и загрузите содержимое этой папки: index.html должен лежать в корне, а не внутри дополнительной папки.
2. Откройте Settings → Pages. Выберите публикацию из ветки main, папку /(root), сохраните.
3. Дождитесь публикации и откройте адрес, который выдаст GitHub. Изменение разделов сайта не требует повторных запросов к серверу.
4. Для гарантированного чтения без связи заранее скачайте index.html. Офлайн-доступ к самой странице GitHub Pages зависит от кэша браузера; автоматический офлайн-кэш сайта здесь не заявляется.

Сайт содержит исходный код учебного проекта. Данные MySQL, пароли сервера, .qtcreator и build не включены. Отметки тренировки хранятся только в браузере, если он разрешает localStorage. Снимок кода фиксирован; при изменении проекта его нужно обновить. SHA256 исходных файлов находятся в source-manifest.json.
